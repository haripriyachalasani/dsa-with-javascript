## 👋 About This Repository  

This repository captures my journey of learning **Data Structures & Algorithms using JavaScript** — built on a structured roadmap, not random practice.

Every problem here is approached with a focus on:
- Understanding **why a solution works**
- Mastering **patterns instead of memorization**
- Building **strong problem-solving intuition**
- Tracking **consistent progress over time**  

If you're also learning DSA with JavaScript, let’s grow together 🚀  

---

## 📖 What is DSA?  

- **Data Structures** → How data is organized and stored  
- **Algorithms** → Step-by-step approaches to solve problems  

📌 The real skill is not just knowing them —  
👉 It’s understanding **when and why to use them**

---

## 🧠 How I Approach Problems  

Instead of jumping directly to code, I follow a structured thinking process:

1. Understand the problem clearly  
2. Identify patterns or similar problems  
3. Think of multiple approaches  
4. Analyze time & space complexity  
5. Write clean and optimized JavaScript code  

📌 Focus:  
> Choosing the right approach > Writing the code  

---

## 🧭 DSA Philosophy  

> Solving more problems doesn’t make you better.  
> Solving problems **deeply** does.

✔ Concept clarity over speed  
✔ Patterns over memorization  
✔ Thinking over copying

## 🗺️ My Learning Strategy  

I follow a **3-Phase Preparation Approach**:

| Phase | Focus |
|---|---|
| 🟢 Phase 1 | JavaScript fundamentals + logical thinking | 
| 🟡 Phase 2 | Core DSA concepts + pattern learning | 
| 🔴 Phase 3 | Real problem solving + contests | 

---

### 🟢 Phase 1: Foundation (0 → Beginner)

**Goal:** Build strong programming fundamentals + logical thinking  

---

#### ✅ Step 1: Learn JavaScript Fundamentals  

- Variables & Data Types  
- Conditions & Loops  
- Functions  
- Arrays & Strings  
- Basic Recursion  
- Input / Output handling  

### 🔹 Must-Know Additions (Important for DSA)

- Time & Space Complexity (basic understanding)  
- Objects (key-value pairs)  

---

⚠️ **Rules:**

- Stick to **JavaScript only**  
- No frameworks at this stage  
- No rushing into DSA  

---

#### ✅ Step 2: Build Logical Thinking  

- Solve basic programming problems  
- Practice beginner-friendly questions  
- Focus on understanding problem statements  

🎯 **Goals:**

- Improve logical thinking  
- Remove fear of coding  
- Learn how to approach problems  

📌 **Focus:**  
> “How to approach a problem” > “How to write code”

---

### 🟡 Phase 2: Core DSA + Patterns  

**Goal:** Learn structured Data Structures & Algorithms  

- Arrays → Graphs  
- Recursion → Dynamic Programming  
- Core Data Structures  
- Pattern-based problem solving  

⚠️ Important:
- Not about solving hundreds of problems  
- Focus on **understanding patterns deeply**  
- Understand **trade-offs between different approaches**

---

### 🔴 Phase 3: Real Problem Solving  

**Goal:** Become interview-ready  

- Solve random problems  
- Practice Problem of the Day (POTD)  
- Participate in virtual contests  
- Track mistakes & revise weak areas  

📌 Focus:
- Thinking under pressure  
- Improving approach & speed
